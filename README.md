# 🌾 Pitanga AgroTech - Tecnologia no Campo

## 🎯 Objetivo
Landing page focada na conscientização e promoção da tecnologia agrícola na cidade de Pitanga, destacando como a inovação impulsiona a economia local e a sustentabilidade.

## 🛠 Tecnologias Utilizadas
- **HTML5**: Estrutura semântica para SEO.
- **CSS3**: Layout fluido com Grid/Flexbox e variáveis.
- **JavaScript**: Manipulação de DOM para componentes dinâmicos e acessibilidade.
